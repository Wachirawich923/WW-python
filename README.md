### ข้อสังเกตเกี่ยวกับข้อมูล
- **การกระจายเบ้ขวา (Right-skewed):** ค่าเฉลี่ยสูงกว่าค่ามัธยฐานชัดเจนในเกือบทุกตัวแปร แสดงว่ามีโพสต์ไวรัลไม่กี่โพสต์ที่ยอดสูงผิดปกติ (Outliers)
- **ผลรวมของแหล่งที่มาไม่เท่ากับ Impressions:** `From Home + From Hashtags + From Explore + From Other` ไม่ตรงกับ `Impressions` ในทุกแถว (ต่างกันตั้งแต่ -282 ถึง +651) จึงไม่ควรสรุปว่าสี่แหล่งนี้รวมกันได้ 100%
- **ความสัมพันธ์กับ Impressions:** `From Explore` (r ≈ 0.89), `Follows` (0.89), `Likes` (0.85) และ `From Home` (0.84) สัมพันธ์สูง ส่วน `Comments` แทบไม่สัมพันธ์ (r ≈ -0.03)
- **ข้อมูลข้อความ:** แคปชั่นยาวเฉลี่ย ~192 ตัวอักษร และแต่ละโพสต์ใช้แฮชแท็กเฉลี่ย ~19 อัน (ตั้งแต่ 10 ถึง 30)
- **ไม่มีคอลัมน์วันที่:** วิเคราะห์แนวโน้มตามเวลาไม่ได้
